# FlytBase Hiring Hackathon Submission

## Project Title
FlytBase Outbound BDR Agent

---

# Overview

This project is an AI-powered outbound BDR workflow that automates the complete prospecting process for FlytBase.

The system accepts a campaign brief, identifies ICP-matched accounts, researches companies using public evidence, discovers relevant contacts, and generates personalized outreach based on verified information.

The workflow is designed to reduce manual prospecting while maintaining high-quality, evidence-backed outreach.

---

# Workflow

The workflow consists of the following stages:

1. Campaign Brief Interpretation
2. ICP Qualification
3. Research Guardrails
4. Account Discovery
5. Contact Discovery
6. Company Research
7. Personalized Outreach
8. Results Dashboard

Each stage performs one specific responsibility before passing the output to the next stage.

# Design Decisions

The workflow follows an evidence-based approach.

Every recommendation is supported using public company information before generating outreach.

This prevents hallucinated company insights and improves the quality of outbound messaging.

The architecture is intentionally modular so that every stage can later be replaced by independent AI agents.
